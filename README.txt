MY GYM — Personal Edition

INCLUDED
- Your confirmed 6-day split (Monday Chest, Tuesday Back, Wednesday Triceps, Thursday Biceps, Friday Shoulders, Saturday Legs, Sunday Rest)
- 37 listed exercises, each starting at 3 sets x 12 reps
- Edit exercise names, set counts, reps and weights
- Remember last-entered exercise weight
- Manual set completion
- 60-second default rest timer, configurable in Settings
- Session history and simple progress chart
- Local AES-GCM encrypted storage, PIN-derived key, encrypted backup export/import
- Light luxury white and emerald-green interface with smooth transitions
- Installable PWA/offline app shell

INSTALL ON ANDROID
1. Upload/extract this folder to a static HTTPS host you control, or serve it from localhost for testing. PWA installation and service workers require HTTPS (localhost is allowed for development).
2. Open the HTTPS page in Chrome on your Android phone.
3. Open Chrome menu and choose Install app (or Add to Home screen, depending on Chrome version).
4. Open MY GYM and create a 4–12 digit PIN.

PRIVACY & BACKUPS
- Workout data is encrypted in this browser's localStorage using AES-GCM. A key is derived from your PIN using PBKDF2-SHA-256.
- The PIN itself is not stored.
- Export encrypted backups regularly. Keep the backup and PIN separately.
- If you forget your PIN and have no usable backup, encrypted data cannot be recovered.
- Clearing browser/site data can erase local records.
- This is a personal prototype, not a security-audited app. Keep your Android device locked and do not use a PIN you use elsewhere.

NOTES
- The browser app is not a native APK. It is an Android-friendly installable PWA.
- The interface works locally once loaded; offline shell caching activates when served over HTTPS/localhost.
- Progress charts use saved session history, not invented/sample data.
